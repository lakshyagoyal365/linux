### ✨ Tips for beginners
- **Start with Ubuntu:** It’s beginner‑friendly, widely used, and has great community support. Learn the basic commands (ls, cd, cat, grep, find, chmod, etc.) here first.
- **Switch based on your work** Once comfortable, explore other distributions like CentOS, Fedora, or Debian depending on your career path (DevOps, SysAdmin, Security).
- **Experiment safely:** Use a virtual machine or Docker container so you can break things without fear.
- **Think in workflows:** Don’t just memorize commands — practice solving problems.
